= Silkie - a terminal emulator with richer input and graphics

Silkie is a terminal emulator for macOS and Linux, forked from kitty. It adds
tablet and touch input, gestures, terminal-side ink, vector graphics, HDR,
and display and presentation feedback.

The main branch is https://github.com/adamdeprince/silkie/tree/silkie[`silkie`].

The link:html/index.html[Silkie homepage] explains the project, features, and
installation. The link:html/developer-guide.html[developer and LLM guide] connects
terminal conventions, kitty's protocols and kitten tools, and Silkie's additions.
The link:html/reference.html[extension reference] specifies those additions.

Build and run Silkie from this branch with `./dev.sh build`, then
`./kitty/launcher/kitty`. See link:html/install.html[installation details].

Build the website with:

[source,sh]
----
python3 -m venv /tmp/silkie-site-venv
/tmp/silkie-site-venv/bin/python -m pip install -r docs/silkie/requirements.txt
make html SPHINXBUILD=/tmp/silkie-site-venv/bin/sphinx-build
----

Open `html/index.html`. This build needs Sphinx and Furo, and does
not require a compiled terminal. Its pages include the extension specifications
from `docs/` and use one shared stylesheet in `docs/silkie/_static/silkie.css`.

kitty extends traditional VT/xterm-style terminal protocols; kittens are its
companion tools and plugins. For inherited behavior, see the
https://sw.kovidgoyal.net/kitty/[kitty manual],
https://sw.kovidgoyal.net/kitty/protocol-extensions/[kitty protocol specifications],
and https://sw.kovidgoyal.net/kitty/kittens_intro/[kitten documentation].
